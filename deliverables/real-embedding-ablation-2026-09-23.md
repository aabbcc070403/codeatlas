# RAG 三路消融（真实模型 + 真实本地嵌入）· 2026-09-23

规格 13 / docs/evaluation.md 要求的「检索增强是否提升生成质量」消融验证。本记录为**提示词 review-prompt-v2**口径（v1 数字见 §4/§4.5 与 09-19 记录，分栏不覆盖），并首次闭环此前唯一未验证项：**pgvector 向量检索路**。

## 1. 运行环境

- **对话模型**：`deepseek-chat`（DeepSeek OpenAI 兼容模式），`evaluation_projects` 全部 `provider=openai、provider_is_mock=false`，`metrics_json.config.realModelRun=true`。
- **嵌入模型（本次新增）**：`local:bge-small-zh-v1.5`（transformers.js + ONNX WASM 后端，512 维，CLS 池化 + L2 归一化；模型文件经 hf-mirror.com 下载，huggingface.co 直连不可达）。本地推理零 API 成本、不占日额度（`isLocal` 跳过预留/结算）。
- **检索模式实证**：嵌入启用后 `retrieve_guidelines` 调用 **29/29 为 `hybrid`（pgvector 余弦 Top10 + 字符二元组词法 Top10，RRF 融合），0 次 `lexical_only` 降级**——向量路真实生效（此前 DeepSeek 无 embedding API 时全部走词法降级）。
- **数据集**：`v1-cd06ca6f`，holdout 8 项目（4 缺陷 + 4 对照）；`EMBEDDING_DIM=512`，索引由 `pnpm reindex` 以本地模型重建（30 条预置规范全部向量化，`chunks.embedding_model=local:bge-small-zh-v1.5`）。
- **提示词**：`review-prompt-v2`（宁缺毋滥：无确凿证据不提交，空结论为正常结果）。

## 4. 如实结论（小样本口径）

1. **向量路闭环**：pgvector 混合检索（RRF）× 真实嵌入真实可用，29/29 检索调用 hybrid，规范引用可回溯（scan_citations）。此前「hybrid_rag 仅词法降级」的限制解除。
2. **检索增强对 P/F1 的影响在 n=8 方差内**（向量列三次 0.600–1.000 波动最大），**不能宣称显著提升**。RAG 的稳定增量在**证据丰富度**（规范引用/命中）与可解释性，而非本样例集的分类指标；检索上下文在小样本上既可能抑制也可能诱发额外告警。
3. llm_no_rag 在本 v2 提示词下最稳定（零方差）：对照项目误报已由提示词护栏压制，检索的边际收益在本数据集上有限；真实项目的长尾场景（规范约束类问题）预期收益更大——此为预期，非实证。
4. 全部结果为 24 样例小样本口径，只说明检测管线在本数据集上的行为。
